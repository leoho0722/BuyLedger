## REMOVED Requirements

### Requirement: Mechanisms depending on non-public identifiers are covered by regression tests

**Reason**: This requirement existed to require regression coverage for the window-level keyboard-dismissal gesture, which matched against non-public type names to exclude touches it must not intercept. That mechanism has been removed and replaced by three named per-screen dismissal paths, and no mechanism anywhere else in the codebase matches non-public type names or other undocumented identifiers. With its only instance gone, the requirement's two example scenarios still describe that removed gesture — one asserts a behavior guarded by "the underlying identifier matching," the other asserts the gesture "still recognizes simultaneously with known scroll recognizers" — and both now directly contradict the keyboard-dismissal-paths requirement that no window-level gesture and no non-public type name matching remain. Keeping the requirement's general clause without a real instance to anchor it would let this same contradiction reappear the next time a scenario is written against it.

**Migration**: Regression coverage for the behavior these scenarios protected already exists: keyboard-dismissal-paths' "Keyboard dismissal does not intercept touches globally" requirement now states that its "System text menu does not dismiss the keyboard" and "Interactive controls are unaffected" scenarios are each asserted by a regression test. No code changes follow from this migration; the tests already assert the correct behavior, only the source-of-truth requirement moves. Should a future mechanism anywhere in the codebase come to depend on matching non-public identifiers, its regression-test obligation should be captured as a requirement scoped to the capability that owns that mechanism, rather than reintroduced as a standalone entry here.
