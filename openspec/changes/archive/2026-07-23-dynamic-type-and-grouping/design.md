## Context

專案的 Dynamic Type 支援目前停在「字會變大」這一層：文字幾乎全數使用語意字級，四個主要數字也正確使用了隨字級縮放的度量。缺的是下一層——版面結構本身不因字級改變。全專案沒有任何一處讀取字級環境值，因此固定欄數的格狀版面、橫排的三欄列、固定點數的欄寬與格高，在無障礙字級下都只能靠截斷或裁切收場。

有兩處更微妙：總覽頁的淨獲利已使用隨字級縮放的度量，卻又接上單行限制與最小縮放係數，等於自己抵銷自己；關鍵指標格同樣以最小縮放係數處理溢出。縮放係數是把「放不下」變成「縮小到看不清」，並非支援。

輔助技術方面的問題不是缺標籤——純圖示按鈕的標籤覆蓋率是全專案做得最好的一塊——而是**顆粒度**。複合列未合併，於是每一列都要滑過所有子元素；熱力圖七十個格子各自成為獨立元素但標籤不含座標，等於朗讀出一串沒有位置的數字。頭像則是相反的問題：它有標籤，但內容與緊鄰的姓名相同，造成重複朗讀。

減少動態效果的偏好目前完全沒有讀取。這不是當下的缺陷（唯一的動畫是短促按壓回饋），而是缺少機制——日後任何轉場都會直接違規。

依賴關係：熱力圖的深度階梯與配色由 hig-blocker-remediation 重寫，本 change 調整同一段程式碼的尺寸與標籤，因此必須排在其後。

## Goals / Non-Goals

**Goals:**

- 讓版面在無障礙字級下改變結構而非截斷內容。
- 移除以縮放係數與單行限制抵銷字級支援的作法。
- 讓輔助技術以「一列一個朗讀單位」的顆粒度走過清單，並讓熱力圖的每個格子帶有位置資訊。
- 建立減少動態效果的因應機制，使後續新增的動畫預設就會遵循。

**Non-Goals:**

- 不處理 blocker 與 suggestion 等級的發現。
- 不新增圖表的資料點無障礙描述。
- 不處理右至左語言的鏡像議題。
- 不重新設計任何畫面的資訊架構。
- 不新增動畫。

## Decisions

### 以字級環境值判斷是否為無障礙字級，而非逐級列舉

版面調整的觸發點採用字級環境值提供的無障礙字級判斷，而非列舉個別級距。理由是系統會演進級距，而「是否為無障礙字級」這個界線是穩定的；逐級列舉會在系統新增級距時靜默失效。

在無障礙字級下的調整一律是「降維」：多欄降為單欄、橫排改直排、隱藏次要的數字裝飾而保留其無障礙標籤。不做字級的細粒度分支。

### 移除最小縮放係數與單行限制，改為允許換行

縮放係數把「放不下」變成「縮小到看不清」，在無障礙字級下等於取消了使用者的設定。改為在無障礙字級時解除單行限制讓文字換行，容器隨之長高。

保留縮放係數作為非無障礙字級下的細微調節是可接受的，但它不得作為唯一防線。判準是：在最大無障礙字級下，文字必須完整可讀而非被縮小或截斷。

### 固定點數的尺寸改為隨字級縮放的度量

熱力圖的星期欄寬與格高、圈狀圖的直徑、以及五處寫死的字級點數，一律改為綁定文字樣式的可縮放度量。其中熱力圖格高原本是型別層級的常數，需改為實例屬性才能使用可縮放度量。

圈狀圖的直徑改為可縮放後，中央文字仍可能在極端字級下溢出，因此併用單行限制與縮放係數作為次要防線——此處縮放係數是可接受的，因為圖形本身已隨字級長大，係數只處理殘餘誤差。

### 複合列以合併子元素的方式成為單一朗讀單位

訂單列、開團列與關鍵指標格改為合併子元素，使輔助技術一次讀完整列。合併後的朗讀內容由子元素依版面順序串接，不需要手工組裝字串——這讓內容變更時朗讀自動跟上。

關鍵指標格內的色點是純裝飾，合併前先將其排除，避免朗讀出無意義的內容。

### 頭像在與姓名同列時排除於無障礙樹

頭像目前無條件帶有以姓名為內容的標籤。在訂單列中它與緊鄰的姓名重複，但頭像若獨立出現則仍需要該標籤。因此改為由呼叫端決定：新增一個表示「僅作裝飾」的參數，訂單列傳入該旗標使頭像被排除，其他呼叫點維持現有行為。

### 熱力圖格子標籤補座標，零值格子排除，整圖提供摘要

格子標籤改為包含星期與週次，數值改以無障礙數值表達而非併入標籤。零值格子排除於無障礙樹外——它們佔了大部分格數且不帶資訊，保留只會讓使用者滑過大量空內容。整張圖提供一句摘要說明涵蓋的週數。

### 減少動態效果以環境值判斷並在動畫來源處統一處理

在既有的唯一動畫來源讀取減少動態效果偏好，為真時不套用動畫。同時將此判斷寫入專案文件，使後續新增的轉場都從同一模式出發，而非各自處理。

## Implementation Contract

#### 行為

- 在最大無障礙字級下，總覽頁淨獲利、關鍵指標格數值、熱力圖星期標籤與格內數字、圈狀圖中央文字皆完整可讀，不被截斷、不被縮小到難以辨識、不溢出其容器。
- 在無障礙字級下，關鍵指標格由兩欄降為單欄；訂單列的右欄狀態與金額改置於左欄下方。
- 五處原本寫死字級點數的元素隨系統字級設定縮放。
- 開啟輔助技術後，訂單列、開團列、關鍵指標格各為單一朗讀單位，一次朗讀出該列的完整內容。
- 訂單列的客戶姓名只被朗讀一次。
- 熱力圖每個非零格子朗讀出其星期與週次位置及訂單筆數；零值格子被略過；整張圖提供涵蓋週數的摘要。
- 開啟減少動態效果後，按壓回饋不再帶動畫。

#### 介面與資料形狀

- 頭像元件新增一個表示僅作裝飾的參數，預設為否以維持既有呼叫點行為。
- 熱力圖格高由型別層級常數改為隨字級縮放的實例屬性。
- 圈狀圖直徑改為隨字級縮放的實例屬性，其對外參數形狀不變。
- 不新增功能狀態欄位；所有調整皆在視圖層以環境值驅動。

#### 失敗模式

- 合併子元素後，若子元素順序與版面順序不一致，朗讀內容會顛倒；合併不改變子元素的宣告順序即可避免。
- 零值格子排除後，若整張圖未提供摘要，使用者在稀疏月份會遇到大片無內容區域而不知原因。
- 頭像的裝飾旗標若在獨立使用的呼叫點被誤設，該處會失去姓名朗讀。
- 無障礙字級下的降維若同時套用在已經是單欄的版面上，會產生非預期的空白；調整前確認該版面在標準字級下的既有結構。

#### 驗收標準

- 於實機將字級調至最大無障礙級距，逐一檢視總覽頁、分析頁、訂單列表、開團列表，確認前述元素皆完整可讀且版面結構已降維。
- 於實機開啟輔助技術，確認訂單列、開團列、關鍵指標格各滑一次即讀完整列，且客戶姓名不重複。
- 於實機開啟輔助技術聚焦熱力圖，確認非零格子朗讀含位置、零值格子被略過、整圖有摘要。
- 於實機開啟減少動態效果，確認按壓回饋無動畫。
- 既有單元測試全數通過；受版面變更影響的 snapshot baseline 重錄後差異僅限預期範圍。
- 字串目錄的中英完整性測試通過。

#### 範圍邊界

**在範圍內：** 無障礙字級下的版面降維；縮放係數與單行限制的移除；固定尺寸改為可縮放度量；五處寫死字級；訂單列、開團列、關鍵指標格的合併；頭像重複朗讀的排除；熱力圖標籤的座標與零值排除；減少動態效果的因應機制。

**在範圍外：** blocker 與 suggestion 等級的發現；圖表資料點的無障礙描述；右至左鏡像；資訊架構重新設計；新增動畫。

## Risks / Trade-offs

- [本 change 與 hig-blocker-remediation 修改熱力圖的同一段程式碼] → 明確排在該 change 之後實作；開始前先確認該 change 的熱力圖離散階梯已落地，並在其成果之上調整尺寸與標籤。
- [合併複合列後，若子元素的朗讀內容過長，單一朗讀單位會變得冗長難以聽完] → 驗收時實際聆聽完整一列，若過長則將次要資訊改以無障礙數值表達而非併入標籤，而非退回不合併。
- [無障礙字級下的版面降維會使畫面在該情境下與設計稿差異明顯] → 這是刻意的取捨：可讀性優先於版面一致性，且僅在無障礙字級下生效，不影響一般使用者看到的畫面。
- [熱力圖零值格子排除後，使用者無法逐格確認某日是否為零] → 整圖摘要與非零格子的位置資訊已足以推斷；若驗收發現確有需求，改為保留零值格子但降低其朗讀優先度。
- [snapshot baseline 於標準字級下不會反映本次的大字級調整，因此測試無法涵蓋主要成果] → 驗收以實機大字級檢視為主要手段，snapshot 僅用於確認標準字級下的版面未意外偏移。
